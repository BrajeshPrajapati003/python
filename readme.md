## 🛠️ Running Python Code

Make sure Python is installed:

```bash
python --version
```

Run a Python file:

```bash
python Hello.py
```

For an isolated Python environment:

```bash
python -m venv .venv
```

### Windows

```bash
.venv\Scripts\activate
```

### Linux / macOS

```bash
source .venv/bin/activate
```
